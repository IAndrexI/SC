Step 1 — Login via Cookie Import

The server has no screen, so login works by copying your session cookies from your browser. Takes ~60 seconds.

① Install Cookie-Editor
Chrome: Chrome Web Store
Firefox: Firefox Add-ons
② Export Cookies
1. Open web.snapchat.com and log in
2. Click the Cookie-Editor icon
3. Click Export → Export as JSON
4. It's copied to your clipboard ✓
